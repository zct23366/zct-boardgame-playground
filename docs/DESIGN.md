# Theme Name: Pixel
# Vibe & Description: Retro pixel art aesthetic featuring 8-bit style graphics, vibrant digital colors, and a nostalgic gaming atmosphere.

# Color
- A diverse range of colors may be selected, but all must be sourced from the Nintendo Entertainment System (NES) Palette. Reference can be made to color schemes from classic games such as "The Legend of Zelda", "Super Mario Bros.", "Pokémon", and "Animal Crossing". Appropriate color combinations must be chosen based on user requirements.

# Font
- Heading & Body: HanChanDianZhengTi_16px (url: https://resource-static.cdn.bcebos.com/fonts/ChillBitmap_16px.woff2)
- Hierarchy specifications: All headings are in uppercase; descriptive text follows sentence case (only the first letter of the first word is capitalized).
# Animation
- Tactile click feedback: Buttons display a downward displacement visual effect (Y-axis translation) when clicked, simulating physical pressing sensation.
- Step animation: Abandon smooth transitions; use the steps() function in CSS to create animations that restore the retro frame-by-frame jagged texture.
- Sound effects (disabled by default, support enabling) or sprite animations triggered when the mouse hovers over elements; click operations have a strong tactile feel, just like pressing buttons on a game controller.
Typesetting:
- Card-based presentation: Products are displayed in the form of "item cards", with clear labeling of attribute values and pixel-style icons.

# Layout
- Card-based presentation: Products are displayed in the form of "item cards", with clear labeling of attribute values and pixel-style icons.

# Elements
- Unless explicitly required, the use of emoji symbols is prohibited.
- Priority is given to generating or searching for pixel-style images for use as fill for component and background images.
All elements have a strong clickable feel, with almost no rounded corners, paired with three-dimensional beveled edges, hard-edged shadows, and thick border designs.
- Utilize bounce animations and flashing text to create an immersive dynamic experience.
- Dialogue popups: Text containers adopt the dialogue bubble style of role-playing games (RPGs), paired with a typewriter effect where text appears character by character.
- Pixel sprite avatars: User-exclusive pixel art avatars that can interactively respond to page scrolling or mouse hovering.
Flashing cursor: Input boxes are paired with square-shaped flashing cursors, consistent with arcade interface styles.
